# Hyber's Blog

> "It's over isn't it"

Personal blog built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/).

Based on the [Hux Blog](https://github.com/Huxpro/huxpro.github.io) theme.

## Local Development

```bash
npm install
bundle install
npm start       # or: bundle exec jekyll serve
```
