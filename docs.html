Tài liệu & Hướng dẫn

Chào mừng bạn đến với trang tài liệu của Hyber.

1. Hướng dẫn tạo bài viết mới

Để tạo bài viết mới trên blog, bạn tạo file Markdown mới trong thư mục _posts/ theo đúng định dạng tên file:

_posts/YYYY-MM-DD-ten-bai-viet.md

Cấu trúc Front Matter mẫu:

---
layout: post
title: "Tiêu đề bài viết"
subtitle: "Mô tả ngắn gọn"
date: 2026-07-29
author: "Hyber"
header-img: "img/hollow-knight.png"
catalog: true
tags:
    - Tech
    - Notes
---

Nội dung bài viết viết bằng cú pháp Markdown ở đây...
